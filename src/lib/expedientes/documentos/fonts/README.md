# Tipografía de los documentos del expediente

`LuxcarsSerif-*.ttf` es una versión modificada de **Source Serif 4** 4.005
(© 2014–2023 Adobe, https://github.com/adobe-fonts/source-serif), distribuida
bajo la SIL Open Font License 1.1 (`OFL.txt`).

Modificaciones:

- Subconjunto latino (Latin-1, Latin Extended-A, puntuación general, monedas,
  flechas y casillas), sin hinting, para que cada archivo pese ≈ 70 KB.
- Nombre de familia cambiado a "Luxcars Serif": la licencia reserva el nombre
  "Source" (*Reserved Font Name*) y no permite usarlo en una versión modificada.

Se incrusta en los PDF (`renderPdf.tsx`) y en los DOCX (`renderDocx.ts`).
